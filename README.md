# goutergraph

コーヒー・紅茶・スイーツの商品情報と写真を保存し、同じ商品に対する体験を積み重ねて振り返るための個人アーカイブです。

現在はプロダクト探索と開発基盤の準備段階です。実装技術、提供形態、MVP の範囲はまだ決定していません。

## ドキュメント

- [ドキュメント索引](docs/index.md): 目的別の読み順と正本の所在
- [プロダクト概要](docs/product/brief.md): 誰の何を解決するか、設計原則、非目標
- [要求](docs/product/requirements.md): 合意済み要求、候補、受け入れ観点
- [ドメインモデル](docs/product/domain-model.md): 用語、関係、不変条件
- [未決定事項](docs/product/open-questions.md): 実装前に判断が必要な論点
- [アーキテクチャ](docs/architecture.md): 現在の技術判断と更新条件
- [意思決定記録](docs/decisions/README.md): ADR の運用方法
- [実行計画](docs/plans/README.md): 長めの開発作業を継続可能にする計画の形式

コーディングエージェント向けのリポジトリ規約は [AGENTS.md](AGENTS.md) にあります。

## プルリクエスト

[PR テンプレート](.github/pull_request_template.md) に沿って、変更の目的、主な変更、検証内容と結果を記述してください。レビュー観点には、判断に迷った点と現時点の判断・理由、確認や助言を求めたい内容を記述します。レビュー観点と備考は、該当しなければ削除できます。

## 開発状況

まだアプリケーションコードと開発コマンドはありません。最初の実装に着手するときは、技術選定を ADR に残し、この README にセットアップ、実行、検証コマンドを追加してください。
