# ADR-0001: MVP をレスポンシブ Web アプリ／PWA として提供する

- Status: Accepted
- Date: 2026-09-29
- Deciders: Product owner

## Context

中心となる利用場面では、商品を見つけた場所や飲食中にスマートフォンで写真を撮り、素早く記録する。一方、蓄積した商品情報の確認・修正には PC の広い画面も利用したい。

MVP では、記録と再発見の価値を早く検証することが優先である。初期から複数のネイティブアプリを配布すると、ストア審査、リリース、プラットフォーム固有実装の負担が増える。

## Decision

MVP はスマートフォンを第一対象としたレスポンシブ Web アプリとして実装し、PWA としてホーム画面へ追加できるようにする。PC ブラウザにも対応し、詳細の確認・修正に利用できるようにする。

初期段階では App Store／Google Play で配布しない。具体的な Web フレームワークは別の判断とする。

## Alternatives considered

- iOS／Android ネイティブアプリ: カメラ、位置情報、オフライン体験との親和性は高いが、MVP の配布・保守範囲が広がるため採用しない。
- PC 向け Web アプリのみ: 詳細編集には適するが、商品を見つけたその場での記録に合わないため採用しない。

## Consequences

- Positive: 1 つの提供形態でスマートフォンと PC の利用場面を検証できる。
- Positive: URL から利用でき、初期配布と更新を単純化できる。
- Negative: カメラ、位置情報、バックグラウンド処理、オフライン動作にはブラウザと OS による制約がある。
- Negative: ネイティブアプリと同等の操作感を保証できない。
- Follow-up: 対象ブラウザ、インストール要件、オフライン時の保存動作を実装前に具体化する。
